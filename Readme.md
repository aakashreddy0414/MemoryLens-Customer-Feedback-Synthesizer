# MemoryLens – Customer Feedback Synthesizer

## About the Project

MemoryLens is a customer feedback analysis dashboard that helps analyze customer reviews and compare feedback across different months.

## Features

- Positive and negative feedback analysis
- Customer topic identification
- January vs March comparison
- Feedback visualization
- AI-style insights
- Interactive Streamlit dashboard

## Technologies Used

- Python
- Pandas
- Streamlit
- Git
- GitHub
